# WiiTogether prototype asset sources

These files support a local visual prototype. They are not a representation of
Nintendo endorsement, and this document does not grant redistribution rights.
Keep the source and ownership information with the assets.

- `wii-logo.svg`: Nintendo Wii wordmark, Wikimedia Commons
  <https://commons.wikimedia.org/wiki/File:Wii.svg>. The source identifies it as
  a public-domain text logo and a Nintendo trademark.
- `cursor.png`, `back.png`, `backhover.png`, `forward.png`, `forwardhover.png`,
  `bg.png`, `bottom.png`, `main.ttf`: Wii-menu reference assets from
  <https://github.com/danintosh/Wii-Menu-HTML>, downloaded from its `main` branch.
  The repository distributes these as Wii-menu recreation assets; original
  Nintendo artwork/font ownership is not transferred by this prototype.
- `RMCE01.png`, `RZTE01.png`, `RMGE01.png`, `RSBE01.png`, `SUPE01.png`:
  US Wii cover images from <https://art.gametdb.com/wii/cover/US/>.
  Cover artwork belongs to the respective publishers. They are demonstration
  library artwork, not bundled game content.
- `join-preview.svg`: generated demonstration QR containing explanatory text,
  not a live PartyPad join URL.

Silver panels, player-card layouts, controller line icons, gradients, carousel
transforms, and synthesized menu tones are authored for this prototype.
`header-swoop.svg` is an original scalable header panel authored for WiiTogether.
